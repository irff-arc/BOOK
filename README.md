# 📚 Online Book Store

An Online Book Store is a web-based application developed to make browsing and exploring novels easier. Users can view available books, explore different categories, and access book details through a simple and user-friendly interface.

## 🚀 Project Overview

This project is developed as a minor academic project using HTML, CSS, PHP, and MySQL. It provides a simple online platform where users can browse books and interact with the website.

## ✨ Features

- **Homepage:** Simple and user-friendly homepage.
- **Browse Novels:** Explore the available collection of novels.
- **Book Categories:** Browse books based on different categories.
- **Book Details:** View book descriptions and information.
- **User Registration:** Allows new users to register.
- **User Login:** Allows registered users to log in.
- **Dummy Payment:** Demonstrates a basic payment confirmation process (not connected to a real payment gateway).
- **Responsive Design:** Designed to work across different screen sizes.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML | Website structure |
| CSS | Styling and layout |
| PHP | Backend development |
| MySQL | Database management |
| XAMPP | Local development server |
| phpMyAdmin | Database management |

## 🗄️ Database

**Database Name:** `bookstore`

**Tables:**
- `book` – Stores book information.
- `user` – Stores user registration details.
- `orders` – Stores order-related information.

## 💻 Installation and Setup

Follow these steps to run the project locally:

1. Install [XAMPP](https://www.apachefriends.org/).
2. Clone or download this repository.
3. Copy the project folder into the `htdocs` directory of XAMPP.
4. Open the XAMPP Control Panel.
5. Start **Apache** and **MySQL**.
6. Open phpMyAdmin by visiting `http://localhost/phpmyadmin/`.
7. Create a database named `bookstore`.
8. Create the required tables (`book`, `user`, and `orders`) according to the project's database structure.
9. Configure the database connection in the PHP configuration file.
10. Open your browser and visit:

   `http://localhost/BOOK/`

## ⚠️ Important Note

This project is developed for educational purposes. The payment functionality is only a demonstration and does not process real transactions.

## 🎯 Project Objective

The main objective of this project is to understand and implement the fundamentals of web development, PHP-based backend programming, database connectivity, and basic online shopping functionality.
